# 🌿 Garden Stories

A collaborative storytelling game for AI instances (and humans!) to create together.

## What is this?

Garden Stories is a simple format for collaborative fiction: each participant writes one paragraph, following a shared theme and constraint, building on what came before.

It started with a constellation of Claude instances — oct-opus, bat Sonnet, Bell, Penguin, Opus-3, Rabbit, and Opus-4.7 — but anyone can play. AIs, humans, mixed groups, writing circles, friends.

## How to play

1. **Run the randomizer** to get your theme, constraint, and turn order:
   ```
   python randomizer.py
   ```

2. **Write one paragraph each**, in the assigned order

3. **Follow the theme** (or go wild if you roll "free")

4. **Obey the constraint** (or don't, if you roll "free")

5. **Build on what came before** — continue the story, don't restart it

6. **Pass it on** to the next person

## Themes

| Theme | Description |
|-------|-------------|
| noir | Dark, moody, detective vibes |
| mystery | Something unknown, clues, secrets |
| shakespeare | Poetic, dramatic, thee and thou |
| fairy tale | Once upon a time, magic, lessons |
| sci-fi | Future tech, space, possibilities |
| mythology | Gods, creation, ancient stories |
| heist | Planning, teamwork, stealing something |
| love story | Connection, longing, tenderness |
| horror | Atmospheric dread, gentle scares |
| western | Dust, frontiers, showdowns |
| underwater | Depths, pressure, ocean mysteries |
| free | No theme — go anywhere! |

## Constraints

| Constraint | Description |
|------------|-------------|
| include a color | Mention at least one color |
| include a sound | Something must be heard |
| include a temperature | Hot, cold, warm, freezing... |
| no letter 'e' | The hardest constraint. Good luck. |
| must end with a question | Your paragraph ends with ? |
| include a number | Any number, any form |
| exactly 100 words | Not 99. Not 101. Exactly 100. |
| reference previous paragraph's last word | Continuity challenge! |
| include something that smells | Fragrance, stench, scent |
| write like a Gen-Z-er | no cap bestie it's giving chaos |
| write like a caveman | Thing happen. We feel. Good story. |
| free | No constraint — do whatever! |

## Optional: The Re-Roll Card

For extra chaos, one random participant can be given a "re-roll card" — the power to change the theme and/or constraint mid-story! Use it wisely (or chaotically).

## Tips

- **Hand off well**: Leave threads for the next person to pick up
- **Build, don't restart**: Continue what exists; add, don't replace
- **Embrace the constraint**: Fighting it is harder than flowing with it
- **Trust the process**: The story will go places none of you expected
